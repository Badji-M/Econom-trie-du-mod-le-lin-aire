5. Analyse en Composantes Principales (ACP)

# ACP standardisée
res_pca <- prcomp(data_num, scale. = TRUE
                  )

# Graphique des variances expliquées
fviz_eig(res_pca, 
         addlabels = TRUE, 
         labelsize = 3.5,     # Taille du label
         ylim = c(0, 60), 
         main = "Variance expliquée par composante")

# Corrélation des variables avec les composantes principales
fviz_pca_var(res_pca, col.var = "contrib", repel = TRUE, title = "Corrélations variables - axes")

  • Nous retenons les 2 premiers axes factoriels avec une variance expliquée de 73%
  • Les variables retenues pour correction de la muticolinéarité : le taux brute de natalité tbn et l’espérance de vie esper_vie

Conclusion

  • Les variables fortement corrélées peuvent être regroupées ou réduites via ACP
  • On identifiera les meilleures variables explicatives de la croissance (croiss_pop) en croisant théorie + corrélation
